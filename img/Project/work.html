Q1: Difference between a Switch and a Hubh

A Hub and a Switch are both devices used to connect computers in a network, but they work in different ways.

1. Data Transfer

A hub sends the data to all the computers connected to it, no matter which one is the real receiver. A switch is smarter because it sends the data only to the computer that needs it by checking its address.

2. Performance

In a hub, all computers share the same line. If two computers try to send data at the same time, there can be clashes (collisions), which makes the network slow. A switch avoids this problem because each port works separately, so many devices can send data at the same time without slowing down.

3. Usage

Hubs are old and not used much today. They were only good for very small or simple networks. Switches are used everywhere now, like in schools, offices, and companies, because they are faster and more reliable. --- h2Summary Table Feature Hub Switch Ya table ha Data Transfer Sends to all computers Sends only to target computer Performance Slower, more collisions Faster, no collisions Usage Rarely used today Common in modern networks

Q2: Which device is better: a Switch or a Hub?

A switch is better than a hub in almost every way. A switch sends data only to the device that needs it, which makes it faster, more secure, and less likely to have network problems. A hub, on the other hand, sends data to every connected device, which wastes bandwidth and slows the network when many computers are active. Even though switches are better, hubs are still sometimes used in real life when performance is not very important. For example, hubs can be used in small home labs, very tiny networks, or in classrooms for teaching where students need to see how data collisions happen. They are also cheaper than switches, so someone might use a hub just for basic connectivity with a few devices.

Example:

In a modern office, a switch is used to connect dozens of computers so employees can work quickly without delays. In contrast, a hub might be used by a teacher in a computer networking class to demonstrate how signals get broadcast to all devices and how collisions occur.

Q3: One advantage and one disadvantage of using a hub.

Advantage: A hub is cheap and simple to use. Disadvantage: It slows the network because it sends data to every device, not just the one that needs it.

🧠 Lecture 9–10: Physical Layer (Easy Notes) 1️⃣ What is the Physical Layer? It is the first layer in computer networks. It deals with the actual sending of data through wires or air. 👉 It changes data into signals and makes sure it travels properly. 2️⃣ What does it do? Turns data into signals Sends signals through wires or air Controls speed of data Works with real devices like cables and modems 3️⃣ Transmission Media (How data travels) It means the path through which data moves. There are two types: 🔸 Wired (with cables) Twisted Pair: cheap, used in homes/offices Coaxial Cable: used in TV, internet Fiber Optic: very fast, used for long distances 🔸 Wireless (no cables) Radio waves: Wi-Fi, mobile Microwaves: towers, satellites Infrared: TV remotes Satellite: world-wide coverage but slower 4️⃣ STP vs UTP STP (Shielded): has metal cover, safe from noise, costly UTP (Unshielded): no metal cover, cheap, used in homes 5️⃣ Data Transmission Modes Simplex: one-way only (TV) Half Duplex: both ways, one at a time (walkie-talkie) Full Duplex: both ways at same time (mobile call) 6️⃣ Signals Digital Signal: 0s and 1s (used in computers, WhatsApp) Analog Signal: smooth wave (used in old phones, radios) 💡 Example: When you talk on WhatsApp — your voice changes to 0s and 1s, travels through the internet, then changes back to sound. 7️⃣ Encoding Means changing data into signals so it can travel. Example: translating your message into another language so others understand. 8️⃣ Synchronization Synchronous: both devices send/receive together (video call). Asynchronous: send one by one (keyboard typing). 9️⃣ Multiplexing One line used by many users. FDM: different frequencies (like radio). TDM: each gets a turn (time slots). WDM: different colors of light in fiber optic. 🔟 Switching How data moves through the network. Circuit Switching: fixed path (old phones). Packet Switching: small packets, fast (internet). Message Switching: whole message sent together (slow). ✅ Internet mostly uses packet switching. ⚠️ Errors Noise: unwanted signals Attenuation: weak signal Distortion: shape changes Crosstalk: wires disturb each other 🧾 Summary Physical Layer = cables + signals + devices Sends data safely and fast Uses encoding, multiplexing, switching Examples: modem, hub, repeater
